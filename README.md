# Projetos da disciplina

Repositório para organizar as atividades de desenvolvimento web do semestre.

## Aula 01 — Primeiros passos com desenvolvimento Web

Na primeira aula, iniciamos um projeto Web com **Vanilla JavaScript**, isto é, JavaScript sem o uso de frameworks. A estrutura da aplicação é escrita em **HTML**, que organiza o conteúdo; o **CSS** define a apresentação visual; e o **JavaScript** adiciona comportamento e interação à página.

O desenvolvimento é feito em uma **IDE** (Ambiente de Desenvolvimento Integrado), que reúne recursos para editar e organizar os arquivos do projeto. O **GitHub** hospeda o repositório e mantém o histórico das alterações por meio de commits, facilitando o acompanhamento e a colaboração.

Por fim, o projeto pode ser publicado com a **Vercel**. Ao conectar o repositório do GitHub à plataforma e configurar o projeto, a Vercel cria uma versão acessível pela Web. Novas alterações enviadas ao GitHub podem iniciar novas implantações.

### Conceitos principais

- **HTML:** estrutura e conteúdo da página.
- **CSS:** cores, tipografia, espaçamento e layout.
- **JavaScript puro:** lógica e interatividade sem framework.
- **IDE:** ambiente para criar e editar os arquivos do projeto.
- **GitHub:** hospedagem do código e histórico de versões.
- **Vercel:** publicação do projeto Web.

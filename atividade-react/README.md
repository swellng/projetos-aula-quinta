# Estuda+ — Organizador de estudos

Aplicação de lista de atividades construída com React e Vite para a atividade de desenvolvimento de um projeto Web.

## Recursos

- Adicionar atividades e escolher uma categoria.
- Marcar e desmarcar atividades concluídas.
- Filtrar por todas, pendentes ou concluídas.
- Remover atividades.
- Salvar a lista no armazenamento local do navegador.
- Acompanhar o progresso em uma barra visual.

## Executar localmente

1. Instale uma versão atual do Node.js.
2. Dentro desta pasta, execute `npm install`.
3. Execute `npm run dev` e abra o endereço local exibido no terminal.
4. Para gerar os arquivos de publicação, execute `npm run build`.

Na Vercel, configure a pasta raiz do projeto como `atividade-react`. O comando de build é `npm run build` e a pasta de saída é `dist`.

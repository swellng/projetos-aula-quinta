# Aula 07 — CSS Box Model e Flexbox

Abra `index.html` em um navegador. A página contém 20 elementos semânticos e folhas externas de CSS. Cada caixa tem conteúdo textual e valores declarados para padding, border e margin; `box-sizing: border-box` ajuda a interpretar dimensões.

O contêiner usa propriedades Flexbox e os 20 cartões recebem valores próprios de `flex` e `order`. Em telas pequenas os cartões ocupam a largura disponível. A atividade apresenta os conceitos do modelo de caixa e distribuição flexível; para a entrega, capture uma tela do navegador em desktop e outra em largura móvel.
